## Approved Implementation Tasks

### 1. Add Input Validation to `_enumerate_unified_sites()`

**Location:** `src/metalsurfer/placement/site_enumeration.py:460-476`

**Rationale:**
An empty `Atoms` object passed to `_enumerate_unified_sites()` proceeds to `_derive_top_layer_tolerance()` and `_bounding_box_cell()`, crashing with `ValueError: zero-size array to reduction operation minimum which has no identity`. Early validation produces a clear, descriptive error.
*Note: Do NOT add an unconditional `cell_has_volume(cell)` check; nanoparticles and non-periodic clusters intentionally have zero-volume cells and rely on lines 496–504 to synthesize a bounding-box cell.*

**Implementation:**
Add an empty-structure check at the entry of `_enumerate_unified_sites()`:
```python
def _enumerate_unified_sites(
    atoms: Atoms,
    probe_radius: float | None = None,
    max_site_distance: float | None = None,
    top_layer_tolerance: float | None = None,
    material_type: str | None = None,
    pore_threshold: float | None = None,
    enrich: bool = True,
    site_classification_method: str = "auto",
) -> list[Site]:
    """Core site enumeration (single pass, no auto-widen)."""
    if len(atoms) == 0:
        raise ValueError("atoms must contain at least one atom")
    if material_type is None:
        raise ValueError(
            "material_type must be explicitly specified: 'slab', 'nanoparticle', or 'porous'"
        )
    validate_material_type(material_type)
```

### 2. Fix Planar Slab Detection for Primitive & Collinear Top Layers

**Location:** `src/metalsurfer/placement/site_enumeration.py:1048-1079`

**Rationale:**
In `_top_layer_is_planar_from_arrays()`, primitive slab unit cells (e.g. 1×1 fcc(111) with only 1 or 2 atoms in the top layer) trigger `if len(top_indices) < 3: return False` (line 1068). Similarly, collinear top layers trigger `if rank < 3: return False` (line 1075). Both falsely classify flat slabs as non-planar, causing unnecessary and failing 3D Voronoi attempts. Because `top_mask` already filters atoms within `top_layer_tolerance`, checking height variance along the slab normal (`np.var(h) < z_variance_threshold`) correctly identifies planarity for both cases.

**Implementation:**
Update `_top_layer_is_planar_from_arrays()`:
```python
def _top_layer_is_planar_from_arrays(
    positions: np.ndarray,
    cell: np.ndarray,
    top_layer_tolerance: float = _PLANAR_TOP_LAYER_TOLERANCE_ANGSTROM,
    z_variance_threshold: float = _DEFAULT_PLANAR_Z_VARIANCE_THRESHOLD,
    *,
    top_mask: np.ndarray | None = None,
) -> bool:
    """Check whether the topmost atomic layer of *positions* is approximately flat."""
    positions = np.asarray(positions, dtype=float)
    cell = np.asarray(cell, dtype=float)
    if top_mask is None:
        top_mask = top_layer_mask_by_normal(positions, cell, float(top_layer_tolerance))
    top_indices = np.nonzero(top_mask)[0]
    if len(top_indices) == 0:
        return False
    top_pos = positions[top_indices]
    h = _height_along_slab_normal(top_pos, cell)
    if len(top_indices) < 3:
        return float(np.var(h)) < z_variance_threshold
    xy = _project_to_slab_plane(top_pos, cell)
    A = np.column_stack([xy[:, 0], xy[:, 1], np.ones(len(xy))])
    coeffs, _residuals, rank, _ = np.linalg.lstsq(A, h, rcond=None)
    if rank < 3:
        return float(np.var(h)) < z_variance_threshold
    h_pred = A @ coeffs
    return float(np.var(h - h_pred)) < z_variance_threshold
```

### 3. Elevate Symmetry Fallback Log Level

**Location:** `src/metalsurfer/placement/site_context.py:162-167`

**Rationale:**
When `SymmetryAnalysisError` is raised in `resolve_site_context_for_sampling()`, metalsurfer falls back to the unreduced clustered Voronoi site set. Under default production log levels (`WARNING`), the current `logger.info()` is suppressed. Changing this to `logger.warning()` ensures fallback events are visible to users.

**Implementation:**
In `resolve_site_context_for_sampling()`:
```python
        except SymmetryAnalysisError as exc:
            logger.warning(
                "Symmetry site reduction failed; using clustered Voronoi sites (%s)",
                exc,
            )
            symmetry_aware_sites = []
```

### 4. Guard Cache Store Against Duplicate FIFO Evictions

**Location:**
- `src/metalsurfer/placement/site_context.py:99-104` (`_store_site_context_cache`)
- `src/metalsurfer/placement/dissociative.py:272-276` (`get_dissociative_site_pairs`)

**Rationale:**
If two worker threads miss the cache simultaneously and both compute entries for the same cache key, acquiring the lock to insert without double-checking causes redundant FIFO evictions.

**Implementation:**
In `src/metalsurfer/placement/site_context.py:99-104`:
```python
def _store_site_context_cache(cache_key: str, ctx: SiteContext) -> SiteContext:
    with _SITE_CONTEXT_CACHE_LOCK:
        if cache_key in _SITE_CONTEXT_CACHE:
            return _SITE_CONTEXT_CACHE[cache_key]
        if len(_SITE_CONTEXT_CACHE) >= _SITE_CONTEXT_CACHE_MAX_ENTRIES:
            _SITE_CONTEXT_CACHE.pop(next(iter(_SITE_CONTEXT_CACHE)))
        _SITE_CONTEXT_CACHE[cache_key] = ctx
    return ctx
```

In `src/metalsurfer/placement/dissociative.py:272-276`:
```python
    with _DISSOCIATIVE_PAIR_CACHE_LOCK:
        if cache_key in _DISSOCIATIVE_PAIR_CACHE:
            return list(_DISSOCIATIVE_PAIR_CACHE[cache_key])
```
