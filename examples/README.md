# Examples

Run from the repository root after `pip install -e ".[mlip]"`.

```bash
python examples/ethene_ru_slab_binding_energy.py
python examples/run_campaign_yaml.py examples/ethene_ru_slab_binding_energy.yaml
```

`./scripts/run_all_examples.sh` runs the official set. The file list is in the repository [README](../README.md). Production campaigns live under `scripts/`.
